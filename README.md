# 🎬 Netflix Clone

A front-end clone of the Netflix India landing page built using HTML and CSS.

## 🌐 Live Demo

[View Netflix Clone](https://singhyuvraj4512-lab.github.io/Netflix-Clone/)

## Features
- Netflix-inspired homepage design
- Hero section with background image
- Promotional sections with images and videos
- FAQ section and footer
- Responsive layout
- Custom favicon

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## Getting Started

Clone the repository:

```bash
git clone https://github.com/singhyuvraj4512-lab/Netflix-Clone.git
```

Open `index.html` in your browser to view the project.
